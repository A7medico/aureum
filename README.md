# AUREUM — Private Art Advisory & Collection Curation

> *Where vision meets legacy.*

An exclusive private art advisory digital experience built for discerning patrons worldwide. AUREUM curates extraordinary blue-chip acquisitions, private collection curation, and legacy preservation.

---

## ✨ Features

- **Editorial Luxury Aesthetic**: Curated dark palette with gilded champagne gold accents, glassmorphic surfaces, and bespoke typography (*Playfair Display*, *Cormorant Garamond*, *Poiret One*, *Outfit*).
- **Interactive Art Collection Showcase**: Filterable gallery featuring detailed artifact provenance, medium specifications, valuations, and high-resolution visual previews.
- **Patron Journey & Curatorial Services**: Interactive multi-step acquisition journey, advisory overview, and responsive navigation.
- **Private Advisory Application Modal**: Interactive booking and membership evaluation modal with validation and feedback.
- **Fully Responsive & Accessible**: Optimized for desktop, tablet, and mobile with fluid animations and micro-interactions.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic, accessible markup.
- **CSS3**: Custom design system, glassmorphism, responsive grid & flexbox layouts, smooth keyframe animations.
- **Vanilla JavaScript**: Filter system, dynamic modal handling, scroll observers, and mobile navigation.

---

## 🚀 Getting Started

Clone the repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/A7medico/aureum.git
cd aureum
```

Open `index.html` directly or serve with any static HTTP server:

```bash
# Using Python
python -m http.server 8000

# Using Node (npx)
npx serve
```
